### Operating states

| State | Meaning | Can transition to |
|---|---|---|
| `FAULTED` | Halted by a fault. It must be reset, which takes it to STOPPED, before it can run again. | STOPPED |
| `IDLE` | Ready and waiting: no material, no order, or blocked downstream. | RUNNING, STOPPED |
| `RUNNING` | Producing at any speed. | IDLE, STOPPED, FAULTED |
| `STOPPED` | Halted on purpose by an operator or by the schedule. | IDLE, RUNNING |
